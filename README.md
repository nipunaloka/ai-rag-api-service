# HomeLanka RAG API

A FastAPI-based RAG (Retrieval Augmented Generation) chatbot for the HomeLanka real estate marketplace in Sri Lanka.

## Features

- 🤖 AI-powered property search using LangChain and OpenRouter
- 💬 Conversational chat with message history
- 🏠 MongoDB integration for property data
- 📚 Vector embedding with Chroma
- 🔄 Real-time document reloading
- 🌐 CORS enabled for frontend integration

## Prerequisites

- Python 3.8+
- MongoDB (local or cloud)
- OpenRouter API key
